# DVD WIDGET 
This widget creates a cone that bounces around the screen and changes colours when it hits the edge like the DVD logo would. The image can easily be replaced with your own custom image and the colour change can be disabled. This widget is compatible with StreamLabs, OBS and any other program that has local file as an option under browser source. Please credit me if you use my widget.

## STREAMLABS ONLY SETUP
1. Create a new custom widget source
2. Click on the custom code dropdown and the edit custom code button
3. Copy the code from dvdWidget.CSS, dvdWidget.HTML, and dvdWidget.js into their respective tabs. you do not need anything in the custom field tab.
5. Modify the shown code in the JS and CSS tabs until you are happy with the widget

## LOCAL FILE SETUP (ANY PROGRAM)
1. Download dvdWidgetCombined.HTML and move it to a folder where it will not be deleted
2. Create a new browser source
3. Enable the local source option
4. Locate dvdWidgetCombined.HTML on your computer and add it's file path
5. To change the image, the image size, the colour shift or the movement speed you will need to find dvdWidgetCombined.HTML on your computer, open it with any text editor and change the code shown
